## 📌 Overview
This repository contains foundational Python algorithmic implementations covering recursion, sequence generators, and data structure serialization.

## 🚀 Included Programs
1. **`factorial.py`:** Calculates factorial using both iterative and recursive approaches with edge case validation ($0! = 1$).
2. **`fibonacci.py`:** Generates arbitrary lengths of the Fibonacci sequence.
3. **`struct_to_dict.py`:** Implements object serialization converting structured data models into standard Python dictionaries.

## 💻 How to Run
```bash
python factorial.py
python fibonacci.py
python struct_to_dict.py
